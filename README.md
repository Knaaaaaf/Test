# sigma

Minimalistyczna aplikacja webowa zaprojektowana pod telefon. Ma ekran „sigma”, animację i odtwarzacz lokalnego pliku audio. Można dodać ją do ekranu głównego z menu przeglądarki.

## Uruchomienie

Otwórz `index.html` na GitHub Pages lub uruchom lokalny serwer statyczny. Kliknij **Wybierz plik muzyczny z telefonu** i wskaż plik audio. Przeglądarki blokują automatyczne odtwarzanie dźwięku bez interakcji użytkownika; aplikacja nie zawiera utworu „Putin” w repozytorium.

## GitHub Pages

W repozytorium wybierz **Settings → Pages**, jako źródło ustaw **Deploy from a branch**, wybierz branch `main` i folder `/(root)`, a następnie **Save**. Po opublikowaniu strona będzie dostępna pod adresem `https://Knaaaaaf.github.io/Test/`.
